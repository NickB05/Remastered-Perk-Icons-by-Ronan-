# Remastered Perk Icons by: Ronan
This pack, created by Ronan (ronan_m), remasters the original perk and power-up icons from Black Ops 2, offering higher quality and greater fidelity to the original icons seen in Tranzit and Die Rise

# Tutorial

### 1. Download the files

Download or clone this repository.

### 2. Open your Plutonium folder

Navigate to:

```text
AppData\Local\Plutonium\storage\t6
```

### 3. Install the mod

Drag and drop the downloaded folders into the `t6` directory.

> If Windows asks whether you want to replace existing files, choose **Replace**.
